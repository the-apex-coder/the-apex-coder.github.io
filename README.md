# MH — Frontend Developer Portfolio

A responsive, dark-themed personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `MH-Portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Customize
- Contact email and WhatsApp are already configured.
- GitHub is set to `https://github.com/the-apex-coder`.
- In `index.html`, replace LinkedIn, Instagram, X, Facebook, YouTube, TikTok, and Discord homepage links with your own profile URLs.
- Add actual project URLs when available.

Font Awesome icons and Google Fonts load from online CDNs, so an internet connection is needed for those assets.
